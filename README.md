# X și 0

Joc simplu de X și 0 (tic-tac-toe) pentru doi jucători, în browser.

## Cum rulezi

Deschide `index.html` în browser sau pornește un server local:

```bash
python3 -m http.server 8000
```

Apoi accesează http://localhost:8000

## Funcționalități

- Joc pentru doi jucători (X și 0)
- Scor pentru victorii și egaluri
- Evidențierea combinației câștigătoare
- Design modern, responsive
